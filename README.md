# plp-da-a4-student-eda-and-board-report
# PLP Data Analytics Project

## Project Overview

This repository contains two data analytics engagements completed using Python, Pandas, NumPy, Matplotlib and Looker Studio.

### Engagement 1: Student Performance EDA

An exploratory data analysis of student academic performance. The project investigates relationships between study hours, attendance, school type, county and academic outcomes.

**Notebook:** `student_eda.ipynb`

### Engagement 2: Duka Electronics Board Report

An analysis of Duka Electronics' first-half 2026 sales performance. The project explores revenue trends, product contributions, branch performance and sales channels, then presents the findings in a one-page board report and an interactive dashboard.

**Notebook:** `board_report.ipynb`
